# 每日菜单 - 电子菜单应用

一个简单易用的电子菜单应用，可以记录每天的用餐情况，支持历史查询和数据导出。

## 功能特点

### 基础功能
- ✅ **每日点菜记录** - 记录早餐、午餐、晚餐、夜宵/零食
- ✅ **菜品信息** - 支持菜品名称、价格、备注
- ✅ **历史记录** - 查看任意日期的菜单记录
- ✅ **日期筛选** - 按日期范围筛选历史记录
- ✅ **数据导出** - 支持导出为 CSV、Excel、JSON 格式
- ✅ **数据持久化** - 使用浏览器本地存储，数据安全保存
- ✅ **响应式设计** - 完美适配手机和电脑

### 新增功能
- ✅ **菜品库管理** - 创建和管理常用菜品库，可重复使用
- ✅ **原材料记录** - 每个菜品可添加多个原材料及重量
- ✅ **营养计算** - 根据原材料和重量自动计算营养成分
- ✅ **营养显示** - 实时显示每道菜和每餐的营养信息
- ✅ **营养数据库** - 内置常见食材营养成分数据库
- ✅ **菜品选择** - 点菜时可直接从菜品库选择已保存的菜品
- ✅ **草稿保存** - 每次操作自动保存草稿，方便继续编辑
- ✅ **分步操作** - 支持分步添加原材料，随时保存

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 选择日期，添加当天的菜品
3. 在"历史记录"标签页查看过往记录
4. 在"导出数据"标签页导出指定日期范围的数据

## 技术栈

- 纯 HTML/CSS/JavaScript
- 本地存储（LocalStorage）
- 响应式设计
- 无需后端服务器

## 使用说明

### 管理菜品库
1. 切换到"菜品管理"标签页
2. 点击"添加新菜品"按钮
3. 输入菜品名称
4. 添加原材料：点击"添加原材料"，输入原材料名称和重量（克）
5. 系统会自动计算并显示营养信息
6. 可以随时点击"保存草稿"保存当前进度
7. 完成后点击"保存"将菜品添加到菜品库

### 添加菜品到菜单
**方式一：从菜品库选择**
1. 选择要记录的日期
2. 点击对应餐次的"添加菜品"按钮
3. 点击"从菜品库选择"按钮
4. 选择已保存的菜品，会自动填充原材料信息
5. 可以修改原材料或添加新的原材料
6. 点击"保存"

**方式二：手动输入**
1. 选择要记录的日期
2. 点击对应餐次的"添加菜品"按钮
3. 输入菜品名称（可以输入已保存的菜品名称，会有自动提示）
4. 添加原材料：点击"添加原材料"，输入原材料名称和重量
5. 系统会实时计算并显示营养信息
6. 填写价格和备注（可选）
7. 可以随时点击"保存草稿"保存进度
8. 点击"保存"

### 查看历史
1. 切换到"历史记录"标签页
2. 可选择日期范围进行筛选
3. 查看详细的用餐记录

### 导出数据
1. 切换到"导出数据"标签页
2. 选择开始日期和结束日期
3. 选择导出格式（CSV/Excel/JSON）
4. 文件会自动下载到您的设备

## 营养计算说明

系统内置了常见食材的营养成分数据库，包括：
- 主食类：大米、面条、馒头、面包等
- 肉类：猪肉、牛肉、鸡肉、鱼肉、鸡蛋等
- 蔬菜类：白菜、菠菜、西红柿、黄瓜、胡萝卜等
- 豆制品：豆腐、豆浆、豆腐干等
- 调料类：食用油、盐、酱油、醋等

**营养成分包括：**
- 热量（卡路里）
- 蛋白质
- 脂肪
- 碳水化合物
- 膳食纤维
- 钙
- 铁
- 维生素C

系统会根据输入的原材料和重量自动计算总营养，并在以下位置显示：
- 添加菜品时的实时预览
- 每餐的营养汇总
- 菜品库中的营养信息

## 数据存储

所有数据存储在浏览器的 LocalStorage 中，包括：
- 每日菜单记录
- 菜品库数据
- 草稿数据

数据仅保存在本地设备，不会上传到服务器。

## 注意事项

- 数据存储在浏览器本地，清除浏览器数据会删除所有记录
- 建议定期导出数据作为备份
- 如需在多设备间同步，可以考虑将数据导出后手动同步
- 营养数据基于标准营养成分表，实际值可能因食材品质、烹饪方式等因素有所差异
- 如果食材不在数据库中，系统会使用平均值进行估算
