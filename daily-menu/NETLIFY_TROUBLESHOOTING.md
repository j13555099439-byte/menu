# Netlify 部署问题排查

## 问题：手机浏览器显示"无法提供安全连接"

### 可能的原因和解决方案：

### 1. 检查 Netlify 部署状态

**在电脑上：**
1. 登录 Netlify 控制台
2. 查看你的站点状态
3. 确认部署是否成功（应该显示绿色的 "Published"）

**如果显示 "Building" 或 "Failed"：**
- 等待部署完成
- 如果失败，查看错误日志

### 2. 检查网址是否正确

**确保网址格式正确：**
- ✅ 正确：`https://your-site-name.netlify.app`
- ❌ 错误：`http://your-site-name.netlify.app`（缺少 s）
- ❌ 错误：`your-site-name.netlify.app`（缺少协议）

**注意：**
- 必须使用 `https://` 开头
- 不要使用 `http://`

### 3. 清除浏览器缓存

**在手机上：**
1. 清除浏览器缓存
2. 或者使用无痕/隐私模式打开网址
3. 或者尝试其他浏览器（Chrome、Safari、Firefox）

### 4. 检查网络连接

**确保：**
- 手机已连接到互联网
- 可以访问其他网站
- 没有使用 VPN 或代理（某些 VPN 可能阻止 HTTPS）

### 5. 尝试不同的访问方式

**方法1：直接输入完整网址**
```
https://your-site-name.netlify.app
```

**方法2：在电脑上测试**
- 先在电脑浏览器中打开网址
- 如果电脑能打开，说明部署成功
- 问题可能在手机网络或浏览器

**方法3：使用二维码**
- 在 Netlify 控制台，站点设置中可以生成二维码
- 用手机扫描二维码访问

### 6. 检查 Netlify 站点设置

**在 Netlify 控制台：**
1. 进入你的站点
2. 点击 "Site settings"
3. 检查 "Domain management"
4. 确认域名状态正常

### 7. 重新部署

如果以上都不行，尝试：
1. 在 Netlify 控制台
2. 进入 "Deploys" 标签
3. 点击 "Trigger deploy" → "Deploy site"
4. 等待重新部署完成

## 快速检查清单

- [ ] Netlify 部署状态是 "Published"（已发布）
- [ ] 网址以 `https://` 开头
- [ ] 在电脑浏览器中能正常打开
- [ ] 手机已连接互联网
- [ ] 尝试了清除缓存或使用无痕模式
- [ ] 尝试了不同的浏览器
